# HSGG - Gruppe 4A 2

## Voraussetzungen

Die folgenden Tools werden zum Bauen dieses Projekts benötigt:

| Tool     | Version  | Hinweis |
| -------- | :------: | :-----: |
| [JDK]    | `25.0.0` |         |
| [Gradle] | `9.0.0`  |         |

## Verwendung

```sh
$ gradle server:bootRun
```

Öffnen Sie <http://localhost:8080>, um die Anwendung zu starten.
